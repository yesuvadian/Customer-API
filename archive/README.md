# Archive

This folder contains temporary test scripts and documentation files created during development.

## Structure

- **docs/** - Implementation documentation, fix logs, and feature guides
- **test_scripts/** - One-off test scripts, migration utilities, and verification tools

## Contents

### Documentation (docs/)
- Build error fixes and solutions
- Flutter implementation guides
- Multi-session testing documentation
- PDF/HTML preview implementation notes
- Gap analysis and resolution logs

### Test Scripts (test_scripts/)
- Database migration scripts
- Multi-session test scenarios
- Template testing utilities
- Request verification scripts

These files are kept for reference but are not part of the main codebase.
